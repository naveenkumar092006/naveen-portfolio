# Naveen Kumar M — Portfolio

A responsive, single-page portfolio for Naveen Kumar M, Data Scientist and ML enthusiast. The site is built as a standalone static HTML page with inline CSS, JavaScript, SVG artwork, and an embedded profile image.

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server. There is no build step or package installation.

## Hosting

This project is configured for GitHub Pages. The workflow in `.github/workflows/pages.yml` publishes the repository root whenever changes are pushed to `main` and supports manual runs from the GitHub Actions tab.

## Updating

Edit `index.html` and push the changes to the `main` branch. GitHub Actions will publish the update automatically.

## External resources

Google Fonts and Three.js are loaded from their public CDNs. The page remains readable if those services are unavailable, with browser fallback fonts and the non-WebGL content intact.

## Contact and portfolio content

Contact and project links are included in the HTML. Resume and certificate links request a copy by email because the original documents were not included with the supplied portfolio HTML.
